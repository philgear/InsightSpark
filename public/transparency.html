1. Who Pays What (Sovereign Compute Tiers)

Pivot & Pulse (InsightSpark) separates personal well-being and ideation from mandatory cloud billing. Every user and self-hoster can choose between zero-cost local execution, zero-charge open-weight cloud execution, Bring-Your-Own-Key (BYOK), or maintainer-hosted defaults:

  • On-Device Browser RAM (window.ai / WebGPU): $0.00 cloud cost. Runs directly in visitor browser memory with zero network egress and zero server API charges.
  • Local Workstation GPU (Ollama pivotpulse): $0.00 cloud cost. Streams from your own localhost:11434 daemon with permanent VRAM keep-alive and zero cloud quota.
  • Hosted Open-Weight (gemma-4-31b-it): $0.00 per 1M tokens. Hosted through the Gemini API with zero per-token billing even when executed inside a billing-enabled project.
  • Bring Your Own Key (BYOK): You supply your own Gemini API key (stored only in your browser's localStorage) and pay Google directly at published per-token rates—or stay within Google's free tier on eligible models.
  • Maintainer-Hosted Cloud Tier: Subsidized by the project maintainer within rate-limited budgets (20 req / 15 min per IP on /api/*), passing zero prompts or PII to disk.

3. Stateless Cloud Infrastructure & Abuse Guardrails

  • Scale-to-Zero Serverless Hosting: Static Angular bundles are delivered through global CDN caching, while dynamic API endpoints run behind a stateless serverless Express proxy that scales down to zero idle instances ($0.00 idle compute).
  • Cross-Site & Quota Guardrails: API routes enforce strict domain-allowlisted CORS, active IP rate limiting, and hosted-key cost caps (default cloud calls restrict models to the cost-bounded allowlist and cap reasoning at medium, or low for 4-phase debates).
  • BYOK & Zero Disk Retention: Supplying your own API key or selecting window.ai / WebGPU / local Ollama unlocks full model tiers. All Gemini Interactions requests specify store: false, and session cost receipts remain strictly in client memory with zero prompt or PII persistence.
